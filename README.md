# Trabalho 1 - Arquitetura de computadores

Criptanálise de cifras de substituição.

## Como utilizar este repositório

Clone este repositório via `git clone` e navegue para dentro da pasta criada.
No terminal, execute `python3 prog.py simple` para iniciar o algoritmo genético
da cifra de substituição simples, e `python3 prog.py circ` para a cifra de substituição
circular. Hiperparâmetros podem ser customizados em `prog.py`.

Também estão inclusos nesse repositório arquivos de outras métricas de n-gramas,
bem como os scripts usados na geração dos experimentos, os conjuntos de dados em
formato `.csv`, e o notebook usado na produção dos gráficos.

## Uso de IA generativa

O notebook, script dos experimentos, bem como os métodos das classes que fazem
a coleta dos dados foram criados utilizando IA generativa (Claude Sonnet 5.5).
O restante do repositório foi produzido convencionalmente.
